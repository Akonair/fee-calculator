# 费率结算自动计算器 · Fee Settlement Calculator

单文件、零依赖的费率结算工具：输入金额 / 汇率 / 上下游费率，实时算出实收、实付、毛利，一键生成 Telegram 工单并入账。

**🌐 在线使用（GitHub Pages）**：https://akonair.github.io/fee-calculator/
手机 / 电脑浏览器直接打开即用，无需安装；可「添加到主屏幕」像 App 一样打开。

**🖥 本地使用**：双击 `index.html`（或 `fee-calculator/index.html`）即可，无需联网、无需安装。

## 功能

- 上下游双向结算：代收 / 代付，费率、单笔加收（±）、实得汇率
- 多金额多行录入、多规则草稿、**一个商户的多笔业务一键批量入账**
- 多商户工单：下游按商户分组，每段独立成单，汇总单留给自己
- Telegram 工单：所有数字单反引号包裹，**手机上点一下数字即可复制纯数字**
- 账本、统计、筛选、CSV 导出、JSON 备份
- GitHub 云备份：跨设备同步账目与规则

## 四语切换（v11）

页头下拉可切换：**中文 / English / Bahasa Melayu / Tiếng Việt**，选择自动记忆。
四类工单（上游 / 下游 / 汇总 / 账本）全文跟随语言输出，可直接发给对应国家的商户。

## ⚠️ 数据说明（重要）

- 数据保存在**浏览器 localStorage**，不上传任何服务器。
- **网页版与本地文件版是两个独立数据空间**：`https://xxx.github.io/...` 上录入的数据，不会出现在你本地双击打开的 `index.html` 里，反之亦然。
- 跨端迁移方式：在 A 端「导出 JSON」→ 在 B 端「导入 JSON」；或使用应用内的「GitHub 云备份 / 恢复」功能。
- 清理浏览器数据会清空账目，请定期导出 JSON 或使用云备份。

## 更新网页版

仓库根目录的 `index.html` 是 GitHub Pages 的入口（Pages 只认根目录或 `/docs`）。
源文件在 `fee-calculator/index.html`，改动后执行：

```sh
./publish.sh "更新说明"
```

`publish.sh` 会把源文件同步到根目录并提交（推送需你本地已配置 GitHub 凭证）。
